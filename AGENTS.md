# AGENTS.md

## Project guidance

- Keep changes focused and document any new setup, run, or test commands in `README.md`.
- Preserve existing work unless the requested change explicitly includes it.
- Run the relevant checks before committing when the project provides them.
- Never add flashing, strobing, twinkling, or beat-driven brightness changes.
  This applies to every palette, intensity, and manual effect. Keep light steady.
  Use smooth geometry movement and fixed shading for horror. Smooth telemetry motion.
